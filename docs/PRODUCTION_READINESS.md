# Production readiness

TRIPPY Delivery remains a controlled preview. The current release adds persistent commerce workflows and operational configuration, but commercial go-live requires separate owner approval.

Use the current [pilot readiness checklist](PILOT_READINESS.md), [operating guide](COMMERCE_OPERATIONS.md) and [QA record](COMMERCE_QA.md). These supersede earlier prototype checklists and static demo assumptions.

Do not activate customer orders while actual inventory/prices, receiving accounts, coverage/courier capacity, image rights, recovery evidence or required end-to-end QA remain unverified. No automated payment gateway is enabled.
